# Method V0.1：单阶段低维线性图动力学

!!! abstract "当前研究决策"
    V0.1 优先采用**方向一：结构融合**。低维线性动力学直接承担 GNN 的消息传播，从输入和标签端到端训练；不再先训练一个完整 ODE-GNN，再用另一套自编码器模仿它。方向二的双向蒸馏保留为后续候选，只有在单阶段模型通过任务性能与训练效率门槛后才考虑。

## V0 到底验证了什么

V0 给出了一个有价值但有限的正面结果：在已经训练完成的 A-DGN 上，图级 32 维线性潜态可以较好地复现**主要传播轨迹**。Cora 与 CiteSeer 的 16 步测试状态增量 NRMSE 分别为 6.28% 和 8.04%，logit 增量 NRMSE 分别为 4.55% 和 4.58%。这说明高维隐藏轨迹中确实存在可压缩、近似线性的公共演化成分。

它没有验证“可用于联邦共享的动力学代理已经成立”。同一实验的 16 步扰动响应 NRMSE 为 94.45% 和 97.90%，接近“完全没有解释响应变化”的量级；实验也只覆盖两个数据集的 client 0、一个代理随机种子，且阶段二没有报告相对真实标签的代理 ACC/AUC。

| 命题 | V0 证据 | 判断 |
| --- | --- | --- |
| 主状态轨迹可由低维线性潜态近似 | 16 步 state NRMSE 6.28% / 8.04% | 初步支持 |
| 冻结读出下的主要 logit 轨迹可复现 | 16 步 logit NRMSE 4.55% / 4.58% | 初步支持 |
| 小扰动引起的动力学差异被代理保留 | 16 步 response NRMSE 94.45% / 97.90% | 不支持 |
| 代理本身保持真实任务性能 | 未测代理 ground-truth ACC/AUC | 尚未验证 |
| 低维动力学可以跨客户端直接共享 | 尚未做坐标对齐与迁移实验 | 尚未验证 |

因此，V0 应被表述为：**“主轨迹的低维线性化具有可行性，但响应保真和迁移可用性尚未成立。”**

## 为什么要取消两阶段串行流程

V0 的阶段一在代码语义上是正式的 A-DGN/FedAvg 监督训练，而不是自编码器的 `warmup`。但从完整方法的成本看，它确实构成了代理开始训练之前的前置依赖：必须先跑完最多 100 个通信轮，选出每个客户端的最佳验证 checkpoint，之后才能采集轨迹并进行 3200 次本地代理更新。

这一串行关系带来四个问题：

1. **最终要使用的是代理，却必须先得到一个成熟的全尺寸教师。** 教师训练成本没有被代理替代。
2. **模型重复。** A-DGN 与 Koopman 自编码器各自维护编码、动力学和输出路径。
3. **训练目标错位。** 阶段二主要学习教师的隐藏轨迹，真实标签只通过冻结读出间接出现。
4. **静态条件存在捷径。** V0 解码器可以依赖参考状态构造的节点条件恢复公共轨迹，弱化动态潜态对扰动差异的表达。

融合会消除“100 轮之后才能开始代理”的等待，但**不自动保证联邦训练少于 100 轮**。V0.1 是否更快，必须用通信轮数—任务性能曲线和达到目标性能的轮数来验证，不能仅凭模块变少下结论。

## 两条路线的取舍

=== "方向一：结构融合（V0.1）"

    编码器把节点输入提升到低维坐标；图相关的线性算子直接完成多步传播；任务头从最终潜态预测标签。这里的 Koopman 动力学就是 GNN 主干，不再模仿另一个主干。

    **优势**：单阶段、损失短、训练和评价都直接面向真实任务；节点级潜态天然保留节点差异；不需要教师 checkpoint、轨迹库、静态条件或 KL 采样。

    **风险**：固定线性潜动力学可能不够表达复杂异质图；不同客户端仍可能学到不同潜坐标，单独平均算子没有数学意义。

=== "方向二：双向动力学蒸馏（暂缓）"

    本地 ODE-GNN 产生教师轨迹，低维模型蒸馏其动力学；服务端共享低维动力学后，再用共享结果约束本地 ODE-GNN。它保留了非线性教师的表达力，也提供了紧凑的通信对象。

    这条路线至少有三项尚未解决的结构问题：

    - **坐标不唯一**：对任意可逆矩阵 $S_m$，$(E_m,K_m,D_m)$ 与 $(S_mE_m,S_mK_mS_m^{-1},D_mS_m^{-1})$ 表示同一动力学。不同客户端的 $K_m$ 不能直接 FedAvg。
    - **目标循环变化**：共享代理反过来更新教师后，教师轨迹分布改变，刚拟合的代理立即变旧，需要交替更新、停止梯度或慢速教师来稳定闭环。
    - **负迁移难判定**：让本地教师服从全局低维模型可能抹掉本地有用动力学，需要独立任务守门数据判断每次指导是否有益。

    如果未来启用，应从第 0 轮在线蒸馏、采用 EMA 教师，并交换公共探针上的动力学作用或一并对齐编码器；不能先跑完 100 轮，再重复 V0 的串行流程。

| 比较维度 | 方向一：结构融合 | 方向二：双向蒸馏 |
| --- | --- | --- |
| 训练阶段 | 一个端到端阶段 | 教师、学生与反馈交替 |
| 是否需要成熟教师 | 否 | 是，或至少需要慢速在线教师 |
| 任务监督路径 | 标签直接监督最终模型 | 标签监督教师，学生主要模仿教师 |
| 全局共享对象 | 与编码器耦合的低维传播参数 | 对齐后的代理或公共响应 |
| 主要科学问题 | 线性潜传播能否保持任务性能 | 共享代理能否带来教师增益 |
| 当前优先级 | **先做** | 通过 V0.1 后再评估 |

## V0.1 的核心结构

对客户端 $m$ 的图 $G_m=(V_m,E_m)$，记节点特征为 $X_m\in\mathbb R^{n_m\times d_x}$，带自环的对称归一化邻接为 $P_m$。V0.1 保留节点轴，不再把整张图池化成一个向量。

### 1. 节点级非线性提升

$$
Z_m^{(0)}
=E_\phi\!\left(
X_m,\,P_mX_m,\,\log(1+d_m)
\right)
\in\mathbb R^{n_m\times r}.
$$

$E_\phi$ 可以是两层 MLP。邻域特征与度特征只用于构造初始节点潜态；节点信息随后一直保留在 $Z_m^{(\ell)}$ 中，因此不再需要 V0 的静态节点条件 $C$。

### 2. 低维线性图动力学

连续形式定义为

$$
\frac{\mathrm d Z_m(t)}{\mathrm dt}
=\mathcal A_{G_m}(Z_m(t))
=Z_m(t)A_0+P_mZ_m(t)A_1,
\qquad A_0,A_1\in\mathbb R^{r\times r}.
$$

首版用与 A-DGN 一致的固定步长 Euler 离散化：

$$
Z_m^{(\ell+1)}
=Z_m^{(\ell)}+\eta
\left(Z_m^{(\ell)}A_0+P_mZ_m^{(\ell)}A_1\right),
\qquad \ell=0,\ldots,L-1.
$$

该更新对 $Z$ 是线性的，同时包含节点自身的通道演化 $A_0$ 与邻域耦合 $A_1$。它也是真正的图消息传递层：节点 $i$ 的下一状态由自身潜态和归一化邻居潜态共同决定。

若把节点和通道展平，客户端的完整一步算子为

$$
K_{G_m}
=I+\eta\left(A_0^\top\otimes I_{n_m}+A_1^\top\otimes P_m\right).
$$

各客户端节点数和拓扑不同，因此不共享巨大的 $K_{G_m}$；它们共享固定大小的通道生成元 $(A_0,A_1)$，本地图结构 $P_m$ 只在客户端内部参与算子实例化。

为延续 A-DGN 的稳定性偏置，可从

$$
A_0=Q_0-Q_0^\top-\gamma I
$$

开始，并记录离散算子范数与潜态范数随深度的变化。$A_1$ 是否也需要约束应作为消融，而不是在没有结果前写成必要条件。

### 3. 解码与任务目标

最终任务预测直接来自潜态：

$$
\widehat Y_m=R_\omega\!\left(Z_m^{(L)}\right).
$$

可选的输入解码器只承担防止表示坍缩的辅助作用：

$$
\widehat X_m=D_\psi(Z_m^{(0)}),
\qquad
\mathcal L_m
=\mathcal L_{\mathrm{task}}(Y_m,\widehat Y_m)
+\lambda_{\mathrm{rec}}\mathcal L_{\mathrm{rec}}(X_m,\widehat X_m).
$$

首个对照必须包含 $\lambda_{\mathrm{rec}}=0$。如果任务损失已经能塑造有效坐标，就删除输入重建头；融合后不应为了保留“autoencoder”名称而重新引入一套高维教师状态重建。V0 中的 `pred`、`linear`、`output`、`response` 和 KL 损失在此不再需要：传播由模型结构精确规定，标签直接监督最终输出。

V0 的箭头是“训练教师 → 冻结教师 → 生成轨迹 → 训练代理 → 检查模仿误差”；V0.1 从第一轮开始优化最终会部署的模型。非线性集中在输入提升与任务读出中，中间传播保持低维和线性。

## 联邦训练时共享什么

首版应继续使用已经验证过的 FedAvg 生命周期，把 $(E_\phi,A_0,A_1,R_\omega)$ 作为一个耦合参数块聚合。这样可以先回答唯一核心问题：**用低维线性图动力学替代 A-DGN 主干后，任务性能和收敛速度是否成立？**

不能只因为 $A_0,A_1$ 尺寸小就立即单独平均它们。潜坐标存在基变换自由度；编码器各自漂移后，相同矩阵位置不再代表相同动力学方向。只有在编码器保持共享、坐标由公共锚点固定，或算子先通过公共探针作用完成对齐时，才可以研究“只上传动力学矩阵”。

因此 V0.1 分两道门：

1. **模型门**：耦合聚合的单阶段模型达到任务性能与效率要求。
2. **共享门**：在公共坐标或作用对齐成立后，再比较全模型聚合、仅传播块聚合和完全本地训练。

## 可证伪的研究假设

> 非线性节点编码器能够把异质图任务所需的观测提升到较低维坐标，使线性、自身—邻域分解的传播算子在不依赖成熟 A-DGN 教师的情况下，达到接近官方 A-DGN 的真实任务性能，并更早达到可用验证性能。

以下任一结果都会否定或收窄这项假设：

- 在匹配训练预算下，Cora 或 CiteSeer 的客户端配对 ACC 明显低于 A-DGN；
- 降低潜维 $r$ 后性能迅速坍塌，说明“低维”不成立；
- 只有加入非线性传播才能恢复性能，说明固定线性潜动力学表达不足；
- 输入重建很好但任务性能差，说明自编码目标保留了无关信息；
- 只共享 $(A_0,A_1)$ 时性能下降，说明潜坐标尚未对齐。

具体对照、指标和通过条件见[实验分析](experiments/methodv01.md)。

## 方向二何时重新进入主线

只有当 V0.1 证明低维线性传播具有任务容量，却在客户端个性化上明显弱于非线性 A-DGN 时，双向蒸馏才有充分动机。届时它解决的是“保留本地非线性容量，同时交换紧凑动力学”，而不是用复杂闭环掩盖单阶段模型本身尚未通过的容量问题。
