# Method V0.1

V0.1 是独立于 `s0_ode` 的单阶段节点级线性图动力学路径。模型以
`[X, P X, log(1 + degree)]` 编码初始潜态，并重复使用

```text
Z <- Z + eta * (Z A0 + P Z A1)
```

其中 `A0 = Q0 - Q0.T - gamma I`，`A1` 首版不加约束。默认潜维 32、16 个
Euler 步、步长 0.1、`gamma=0.1`，输入重建默认关闭。

## 联邦训练

```bash
/root/anaconda3/envs/torch/bin/python \
  /opt/data/private/xzc/work2/codev0/main.py \
  --model v01_linear --dataset Cora --gpu 0,1 --n-workers 10
```

配置在 `configs/v01_linear_gnn.json`。编码器、`A0/A1` 参数、读出以及显式启用
时的重建头作为一个耦合参数块参与 FedAvg；Adam 动量继续按客户端保留。

运行目录除通用的 `metrics.csv`、`client_best.csv` 和 `result.json` 外，还包括：

- `dynamics.csv`：各传播步潜态 Frobenius 范数、最大增长率、生成元谱范数、
  客户端耗时/峰值显存，以及单轮和累计上传/下载字节；
- `model_cost.json`：可训练参数量和模型状态字节数。

## Gate 0：单客户端检查

```bash
/root/anaconda3/envs/torch/bin/python \
  /opt/data/private/xzc/work2/codev0/scripts/run_v01_single_client.py \
  --dataset Cora --client-id 0 --device cuda:0
```

该脚本不做 FedAvg，只用于确认单图损失、验证集选型、配对测试指标和潜态稳定性。

完整 Gate 0 网格可以用两张 GPU 运行：

```bash
bash /opt/data/private/xzc/work2/codev0/scripts/run_v01_gate0_grid.sh
```

网格固定比较 `r=16/32/64`，并以 `lambda_rec=10` 作为首个输入重建对照。
这里较大的权重用于补偿稀疏节点特征上逐元素 MSE 的小数值尺度；结果中会同时保存
未加权的任务损失和重建损失，避免只看加权总损失。

## 10 客户端完全本地对照

以下命令让 Cora 的 10 个客户端从相同初始化各自训练 100 epoch，不广播参数，也不
执行 FedAvg：

```bash
bash /opt/data/private/xzc/work2/codev0/scripts/run_v01_local_cora_all_clients.sh
```

输出按每客户端最佳验证 epoch 配对测试，并同时报告多数类基线。该路径用于 N1
对照，不应描述为联邦训练。
